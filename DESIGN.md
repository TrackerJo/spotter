# Spotter design
Profiles you manage are created with a name under Profile > Manage profiles, with an inline name field and explicit Create profile action. Each profile has a rename screen and a link to its own progress and workout history. Progress and recent workouts offer a native data-profile picker; this selection never changes the active workout’s logging focus. Ready to start and the session options menu offer Add profiles, listing saved profiles with Add/Added status and inline creation. Profiles added on this phone require no account, second device, or Nearby connection. Up to three participants use the segmented logging picker; larger groups and accessibility text sizes use a menu. The selected name stays visible above workout content and in every set editor. Each participant keeps independent exercises, sets, timers, history, and suggestions. Finish saves all profiles managed on this phone together while a connected friend can continue. Deleting one profile’s workout preserves other participants’ results. Locally managed profiles and workouts without Nearby sync privately through iCloud. Nearby still connects two phones, each of which can log for additional profiles.

Native SwiftUI product interface for one-handed logging between sets. System grouped backgrounds and system typography follow the user’s light or dark appearance. Restrained indigo marks actions and selection; neutral secondary labels carry context. Use compact native list rows, a standard segmented participant picker, monospaced performance and timers, and at least 44-point tap targets.

The start screen suggests a day and offers Change and Start workout. Start workout opens a Ready to start page with a prominent selected day, Change day action, participant list, and optional friend invitation. A bottom Start workout action begins logging; Cancel returns to setup. Joined friends see a waiting status until the host starts. The session overview shows finished exercises and personal time between sets, with Finish and a raised Add exercise action above the native tab bar. Exercise selection uses a searchable sheet with suggested next, remaining planned exercises, and the library. The selected exercise replaces the overview in the same session screen, beneath the persistent participant picker. Each person retains their own exercise selection. A compact set-entry sheet keeps optional actual RIR in the main measurement section for every set, with any prescribed RIR shown inline beside the input. RIR never requires opening More options. The sheet saves only on Log set or Save changes; Cancel never records a draft. Logged sets have no completion toggle or status badges. Warm-up is a distinct set type. Finish exercise sits below the logged sets and returns to the overview. Friends share a training day, with independent exercise focus, personal history, and time between sets. No decorative animation.

Measurements use pounds for weight/assistance/increments, feet for short distances, and miles for longer distances. Set and target entry offer only US units. History, suggestions, chart values and summaries convert legacy metric records accurately. Canonical stored distances stay in meters for compatibility.

Train together leads with a four-digit numeric code and one prominent Join action. Joining enables both friends to log sets for each other automatically and closes the sheet as soon as both participants are connected. There are no logging-permission or iCloud setup steps after joining. Hosts see a large four-digit invitation code instead of the join form, and their invitation sheet also closes once the friend joins. Shared workout sessions show a Nearby status icon in the trailing navigation bar: Wi-Fi when connected and synced, crossed-out Wi-Fi when disconnected. Tapping it opens a compact two-symbol legend with a short explanation and a reconnect action when offline. No connection banner occupies the workout content. A short read-only notice remains when viewing a disconnected friend’s session.

The Train together join sheet opens at a compact 310-point height and can expand, with a visible drag handle. The join step uses a simple stacked heading, short instruction, rounded code field, and full-width Join button without Form dividers or an enclosing card. Joining feedback, errors, and hosting use medium height. The symbol legend uses a compact 360-point sheet. Accessibility text sizes use the large sheet.

Nearby invitations are open only while the Train together sheet is visible. Done or swipe dismissal removes the advertised invitation; unused codes stop accepting connections. Existing friends keep syncing and can reconnect without advertising a new invitation. The invitation screen has no Stop inviting action.

Train together during an active workout opens the invitation flow directly, using the active workout to choose the sheet content. Solo workouts become shared in place when inviting. The start-screen Join a friend action opens code entry when no workout is active. There is no Invite a friend instead button.

In shared workouts Finish confirms Finish my session, saves only the phone owner’s finish time, and removes them from the live participant picker. The friend continues independently. Personal history, duration, and progression become available immediately upon finishing. Shared waiting rooms offer Cancel to either participant, and the remaining friend can begin training if the owner leaves.

In a friend session, both phones can view and log for either person at the same time. Partner editing requires a live Nearby connection and acknowledged state exchange in both directions. Disconnected phones can view both sessions but edit only their own. A persistent status shows connection and syncing state, with a read-only explanation when viewing the friend. Set and target editors retain the revision they opened and refuse stale saves after receiving newer edits. Truly simultaneous changes to the same record retain both versions in Review edits. Independent additions merge, and stable ID tie-breakers keep display ordering consistent. New set drafts refresh their order and working-set slot at save time. Nearby alone transports shared-session revisions, with full replay and acknowledgment after reconnecting. Shared sessions are excluded from personal iCloud snapshots and legacy cloud merges. Saved pairing details restore Nearby after relaunch. Existing saved lock metadata and cloud lock records are ignored.

During a real workout, a personal Live Activity shows the phone owner’s current exercise at left and a running timer at right. The timer starts at their latest completed set anywhere in the current workout, falling back to session start. The second row shows prescribed reps (or time/distance), next working-set RIR, total prescribed sets, and Log set. Missing targets use dashes. Between exercises it offers Open workout. Shared participant focus never changes whose activity is shown. The activity ends when the owner finishes or deletes their session.

ChatGPT follows native navigation and forms. Failed CSV previews offer a contextual Parse with ChatGPT action; the user sees the sharing scope, an editable draft and explanation before returning to the established import review. Progress offers Ask ChatGPT with suggested questions and a bottom composer. Plans offers Suggest a split with goal, schedule, equipment and constraint inputs, then an explicit plan review. Profile holds account connection and disconnect. Eligible requests show Using ChatGPT plan and Manage usage. Data tools read only the phone owner's completed history; suggestions never become logged results automatically. Chats are temporary and cancel when leaving the screen.

Progress chat uses a full-screen native conversation, with the tab bar hidden, trailing neutral user bubbles and plain assistant replies. The title opens model selection; the compact rounded composer stays above the keyboard. Only two short starter actions appear in an empty conversation. Privacy and temporary-chat details live behind Info, while ChatGPT plan status and Manage usage remain beside the composer. Replies stream in place; failed questions remain visible with Retry. Connection, CSV and split helper copy stays brief.

Split suggestions have a dedicated generation and review flow. Entering it begins generation after account connection. Loading shows current activity, elapsed time, placeholder training days and a Stop action. The result shows a brief What changed summary, editable plan name, training days and exercise targets. CSV and import controls are absent. Add plan stays pinned below the preview; new exercises must be classified or matched before it enables. Saving confirms Plan added and prevents duplicate saves.

Chat polish: the composer uses matching 44-point inner control heights and shared padding so single-line text centers with Send. Conversation and composer outer margins align at 20 points. Empty chat uses a quiet centered heading and two neutral prompt rows. Assistant Markdown renders as native paragraphs, headings, lists, aligned tables and selectable code; wide tables scroll horizontally. Copy message is available by long press. Reading earlier content prevents new replies from forcing a scroll to the end; keyboard resizing keeps the end visible only when already following the conversation. Reduced Motion disables animated auto-scrolling.

Per-workout training volume appears on Progress directly below Exercise performance, with a chart and dated workout values following the selected profile and period, and in the workout details summary. It sums logged working weight × reps in lb·reps for the selected participant, converting metric records and excluding warm-ups, assisted and bodyweight sets.
